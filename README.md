# Données de Fish Fillets NG

Les PNG de Fish Fillets NG sont accompagnés de 2 701 variantes WebP ×4 de Fish Fillets 4ever. Chaque variante intégrée partage le dossier et le nom de son PNG. Le manifeste donne les dimensions logiques et les associations de frames nécessaires au rendu.
