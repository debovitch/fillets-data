# Données de Fish Fillets NG

Le [manifeste HD](images/hd-manifest.json) associe chaque chemin logique NG à sa texture WebP canonique. Sur les 3 778 textures, 2 701 utilisent les graphismes ×4 de Fish Fillets 4ever et 1 077 gardent leur version ×2. Le champ `scale` de chaque entrée donne son échelle et `originalSize` ses dimensions dans le jeu.
